# BadPad
The schematics and code of my BadPad (my own custom macropad)
_______________________________________________________________________________
## Features:
- 128x32 OLED Display
- EC11 Rotary encoder (no button)
- 9 SK8612MINI-E LEDS
- 9 Keys
